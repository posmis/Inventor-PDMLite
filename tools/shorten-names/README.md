# Сокращение длинных имён файлов

Отдельная утилита (не часть PdmLite и не плагин Inventor): исправляет ошибку Inventor
«Ссылка преобразована в путь, имеющий недопустимую длину. Полученный документ невозможно использовать».
Программа: `tools/ShortenNames` (C#, окно Windows), в окне «Утилиты» PdmLite — «Сокращение длинных имён файлов».

## Как пользоваться

1. Закройте в Inventor документы из папки проекта (лучше — сам Inventor).
2. Запустите утилиту, выберите **папку проекта** (целиком: ссылки обновляются только в документах этой папки).
3. Ограничения: полный путь не длиннее (по умолчанию 200) и имя не длиннее (100). Inventor не работает с путями
   длиннее 260 символов, а резервные копии в `OldVersions` удлиняют путь ещё примерно на 20 — поэтому запас.
4. «Найти длинные имена» — список «было → станет». «Станет» можно поправить, ненужные строки — снять галочку.
5. «Переименовать…» — предупреждение (в том числе, если Inventor запущен) и подтверждение.

## Как подбирается имя

- Имена из STEP вида `Q1~TO-263…-BR~TO-263…-BR~GJMo_stp` — повторяющиеся части через `~` убираются,
  приписки формата импорта в конце (`_stp`, `_step`, `_igs`, `_iges`, `_sat`, `_x_t`, `_x_b`) — тоже:
  `Q1~TO-263…-BR~GJMo`.
- Если всё равно длинно — имя обрезается, в конце добавляется код из исходного имени (`…_3F2A9`): разные файлы не совпадут,
  а у `X.iam` и `X.stp` новые имена одинаковые.
- Имя занято — добавляется `_2`, `_3`…
- Если длинна сама папка (на имя остаётся меньше 12 символов) — строка красная: сократите имена папок.

## Как переименовывается

1. Ссылки всех документов Inventor папки (с подпапками, без `OldVersions`) читаются через Apprentice
   (документ с недопустимо длинным путём — через временную копию).
2. Документы, которые изменятся на месте, копируются в `%LOCALAPPDATA%\PdmLite\shorten-names\<время>` (там же журнал).
3. Файлы копируются под новыми именами (старые пока остаются).
4. В каждом документе со ссылкой на них ссылки заменяются (по полному пути, а если Inventor не прочитал путь — по имени
   файла) и **проверяются**.
5. Старые файлы удаляются.

Перед записью — второе подтверждение: в каких документах заменятся ссылки и на какие переименовываемые файлы
ссылок в папке не найдено. Если ссылки какого-то документа не прочитались (он может ссылаться на эти файлы),
ничего не меняется. Если в документе не заменилась ни одна ссылка или остались старые — всё возвращается.

Ошибка на шагах 3–4 — всё возвращается как было.

**Перепривязать по журналу…** — если файлы уже переименованы, а ссылки остались старыми (например, прошлым запуском):
выберите `_журнал.txt` или `_переименования.json` из `%LOCALAPPDATA%\PdmLite\shorten-names\<время>` — ссылки на
старые имена заменятся на новые во всех документах выбранной папки (файлы не переименовываются). Журнал работы: `%LOCALAPPDATA%\PdmLite\logs\shorten-names-*.log`.
