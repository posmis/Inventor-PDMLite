# Сбор файлов по списку

Отдельная утилита (не часть PdmLite и не плагин Inventor): находит файлы Inventor по списку имён
в папке с компонентами и копирует их в одну папку — вместе с зависимостями сборок на всех уровнях.
Программа: `tools/CollectComponents` (C#), в окне «Утилиты» PdmLite — «Сбор файлов по списку».

## Как пользоваться

1. В Inventor: «Диагностика сборки» → «Ненайденные файлы» → **«Копировать имена»**.
2. Запустите «Сбор файлов по списку» (PdmLite → «Утилиты…» или `CollectComponents.exe`).
3. Программа покажет список из буфера обмена, спросит папку для поиска, запустит Apprentice и по каждой
   найденной сборке выведет её зависимости: `+` — есть в папке, `-` — нет.
4. Итог: сколько найдено (из списка и зависимостей), что не найдено, одинаковые имена.
5. Выберите папку для результата и подтвердите копирование (**Д**). В ней — файлы и `_отчёт.txt`.

## Правила

- Поиск — **только в выбранной папке** (с подпапками, без `OldVersions`), по имени файла; старые пути из сборок не используются.
- Зависимости сборок, чертежей и производных деталей читаются через Apprentice (нужен Inventor или Inventor View);
  у потерянных ссылок имя берётся из относительного или логического имени файла.
- Несколько файлов с одним именем — берётся самый новый, остальные — в замечаниях.
- Раскладка: компоненты из списка — все вместе в выбранной папке; состав каждого (все уровни) — в подпапке
  с именем компонента (`Жгут блока электроники_1\…`), только если состав есть.
- **Каждый файл копируется один раз:** файл из списка — только наверху; общая деталь — в папке первого
  компонента списка, которому она нужна.
- Исходные файлы не меняются; у копий снимается «только чтение».
- Повторный запуск в ту же папку перезаписывает прошлые копии (даже «только чтение»). Папка результата внутри папки
  поиска — с предупреждением: при следующем запуске копии найдутся как файлы-дубликаты.

Командная строка (всё необязательно): `CollectComponents.exe --list список.txt --source "D:\Компоненты" --target "D:\Собрано" [--no-deps]`.
