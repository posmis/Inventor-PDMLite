# Первый релиз PdmLite 0.1

Два результата одной сборки:

- `PdmLite-Setup-0.1-Online.exe`: Explorer, плагин и начальная библиотека внутри; PostgreSQL скачивается при первой установке.
- `PdmLite-Setup-0.1-Offline.exe`: дополнительно содержит установщик PostgreSQL; интернет при установке не нужен.

Оба варианта требуют установленного **Inventor 2025, Windows x64**. Inventor в комплект не входит. Explorer и помощник установки содержат .NET 8; плагин использует .NET среды Inventor. .NET SDK требуется только на компьютере сборки.

## Что сделать на компьютере сборки

1. Закрыть Inventor и PdmLite Explorer.
2. Один раз установить [.NET 8 SDK x64](https://dotnet.microsoft.com/download/dotnet/8.0) и [Inno Setup 6.3 или новее](https://jrsoftware.org/isdl.php). После установки открыть новый терминал, если используете командную строку.
3. Сохранить резервную копию PdmLite как `%USERPROFILE%\Documents\PdmLite-Library-ver-0.1.zip`. Для перенаправленных «Документов» используется реальная системная папка, включая OneDrive. Архив в Git добавлять не нужно.
4. Открыть папку **исходников**, где лежат `PdmLite.sln`, `deploy` и файл **`build-installers.cmd`**. Дважды щёлкнуть последний. Папка `Документы\PdmLite` на скриншоте — данные приложения, не исходники.
5. Дождаться сообщения «Готово». Откроется `artifacts\release` с двумя EXE и `SHA256SUMS.txt`.

Если исходников на компьютере нет: скачать ZIP ветки `work` из GitHub, распаковать и выполнить шаг 4. Репозиторий: https://github.com/posmis/Inventor-PDMLite/tree/work (Code → Download ZIP).

Сборка требует интернета для NuGet и получения PostgreSQL, даже если готовится автономный установщик. Можно передать ранее скачанный официальный EXE PostgreSQL; его SHA-256 всё равно проверяется:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\deploy\build-release.ps1 `
  -LibraryBackup 'C:\Users\ilyap\Documents\PdmLite-Library-ver-0.1.zip' `
  -PostgreSqlInstaller 'D:\Downloads\postgresql-16.14-1-windows-x64.exe'
```

Компилятор Inno Setup автоматически ищется в PATH, реестре Windows, обеих папках Program Files и пользовательской папке Programs. Если он установлен в нестандартное место и не найден, передайте `-IsccPath 'D:\Inno Setup 6\ISCC.exe'`.

Путь к исходникам вычисляется автоматически относительно скрипта. Выходные файлы и копия библиотеки находятся в игнорируемой Git папке `artifacts`. Установщики содержат **полную копию переданной библиотеки**: распространяйте их только тем, кому она предназначена. Если библиотека слишком велика для единого EXE, Inno остановит сборку; разделение установщика на части пока не предусмотрено.

## Что происходит при установке

Установщик запускается от имени обычного пользователя. Он проверяет Inventor 2025 и просит закрыть приложения. Бинарные файлы устанавливаются в `%LOCALAPPDATA%\PdmLite`, манифест — в `%APPDATA%\Autodesk\Inventor 2025\Addins`.

При первой установке выбирается пустая папка библиотеки. По умолчанию это системная папка «Документы» текущего пользователя + `PdmLite\Library`. Имя `ilyap` в установщик не зашивается.

Только установка PostgreSQL требует подтверждения UAC и прав администратора. Используется отдельная служба `pdmlite-postgresql-16`, порт **55439**, база и роль `pdmlite`. Уже установленные экземпляры PostgreSQL не перенастраиваются. Если на компьютере уже есть другая установка PostgreSQL 16 без настроенного подключения PdmLite, автоматическая установка остановится: существующий сервер нужно подключить вручную через настройки PdmLite. Это защищает его от неявного обновления установщиком EDB. Сервер PdmLite слушает только localhost. Программа использует обычную роль, не суперпользователя. Пароли генерируются независимо для каждой установки и шифруются DPAPI для пользователя Windows.

Для PostgreSQL закреплены HTTPS-адрес и SHA-256 из официального манифеста winget (`deploy/installer/postgresql.json`). Контрольная сумма проверяется при сборке и установке. Смена версии PostgreSQL требует обновить URL и hash по официальному манифесту.

После создания базы применяются миграции, проверяется и восстанавливается ZIP штатным `LibraryBackupService`: каталог, категории, свойства, версии, связи и файлы. Настройки подключения публикуются после успешного восстановления. Состояние прерванной установки сохраняется в `%APPDATA%\PdmLite\setup-pending.json`; повторный запуск использует те же пароли и папку. При обнаружении компонентов в незавершённой базе автоматическая замена запрещается: восстановление нужно завершить вручную, чтобы не затереть данные.

Если `database.json` уже существует, начальный архив **не восстанавливается**: выполняются только миграции существующей базы и регистрация плагина. Существующие настройки библиотеки сохраняются. Повреждённый файл настроек вызывает ошибку, а не молчаливую установку поверх данных.

Обновление выполняется запуском нового установщика от имени того же пользователя Windows. Удаление программы сохраняет библиотеку, резервные копии, настройки и службу PostgreSQL. Суперпользовательский пароль локального экземпляра сохранён зашифрованным в `local-postgres-admin.json`; это служебный файл, не распространяйте его и не удаляйте без необходимости.

## Проверка перед публикацией

Проверить на отдельной Windows-машине или виртуальной машине с Inventor 2025:

1. Online: свежая установка с интернетом, запуск Explorer, наличие компонентов и открытие их в Inventor.
2. Offline: отключить интернет **до запуска** установщика; повторить свежую установку.
3. Установить поверх настроенного PdmLite: настройки, добавленные компоненты и файлы должны сохраниться.
4. Прервать настройку PostgreSQL/отклонить UAC; повторить установку. Проверить понятную ошибку и продолжение без удаления файлов.
5. Удалить PdmLite: библиотека и база должны сохраниться; переустановить и проверить доступ.

Windows CI собирает помощник, проверяет синтаксис PowerShell и компилирует оба рецепта Inno с фиктивными файлами. Это проверка упаковки, **не** установка реального PostgreSQL или запуск Inventor. Полная проверка требует вашей библиотеки и Windows.

После успешной проверки создать тег `v0.1` на проверенном коммите и GitHub Release `PdmLite 0.1`, приложить два EXE и `SHA256SUMS.txt`. Рекомендуется отметить этот первый выпуск как предварительный. Скрипт не публикует релиз автоматически. Издатель в установщике не указан; цифровой подписи пока нет, Windows может показать предупреждение о неизвестном издателе.
