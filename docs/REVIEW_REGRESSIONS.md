# Регрессионные проверки девяти замечаний ревью

База сравнения — `b77ed99`. Пункт про `Documents.CloseAll(true)` не входит в этот
набор: его семантика требует отдельной проверки в Inventor. Вызов не изменялся.

## Сначала воспроизведение

До исправлений целевой прогон дал 14 падающих проверок: четыре в Core.Tests и
десять в Library.Tests. Файловое резервирование из InventorAssemblyComponents
сначала было вынесено в DocumentBackupSet без изменения поведения, затем проверено
на реальных файлах. Таким образом, тесты проверяют используемый компонент
резервирования, а не копию его алгоритма в тесте.

Добавлено 16 новых тестовых случаев; дополнен существующий тест ошибки запуска
модулей. Итоговые наборы: Core.Tests — 385, Library.Tests — 563. Все 948 прошли,
без пропусков. PostgreSQL-интеграция выполнялась с PDMLITE_TEST_PG.

## Совместимость и цена проверок

- Проверка плана теперь блокирует операцию при любом непрочитанном документе проекта,
  включая DWG, который Apprentice не смог распознать. Продолжать с неизвестным составом
  небезопасно. После устранения проблемы чтение повторяется автоматически.
- Состояние индекса с ошибкой сохраняет старые ссылки как справочные; это не разрешение
  использовать их для изменения проекта. API ReadErrorAsync и панель показывают отказ
  явно. Схема БД не менялась.
- Фиксация объединения происходит по одному удаляемому компоненту, как и раньше.
  Успешно выполненные предыдущие компоненты группы не откатываются при следующем сбое.
- Новая проверка архива требует дополнительных проходов хеширования файлов и повторного
  чтения БД, поэтому создание больших копий станет медленнее.
- Проверка согласованности оптимистическая: обнаруженное изменение приводит к отказу,
  а не блокировке стороннего Inventor на всё время копирования. Она не является общей
  транзакцией PostgreSQL/файловой системы и не защищает от аварийного завершения процесса.
- Уже существовавшие до начала копирования внешние изменения файлов сохраняются как
  раньше. Manifest содержит хеш фактически скопированных байтов; БД при этом не правится.

## Что исполнено и что осталось проверить

Тесты исполнены локально на Linux с настоящей PostgreSQL. Отказ файловой операции
на Linux моделировался правами каталога; в том же тесте для Windows предусмотрена
блокировка файла открытым дескриптором без FileShare.Delete.

Собраны модули связей, библиотеки и переименования, а также проверочная сборка окон
Explorer. Сам AddIn с Inventor API не собран и не запускался: в среде нет
Autodesk.Inventor.Interop.dll и Inventor COM. Для пункта о копиях проверен извлечённый
файловый компонент, включённый в AddIn, а не реальные вызовы замены Inventor.
Реальное поведение Apprentice и визуальное отображение ошибки панели требуют
Windows-прогона. Изменения подготовлены локальным коммитом; push не выполняется.
