# Стандартная библиотека PdmLite

Первая главная функция. Статус: **требования согласованы, реализация не начата.**

Единая для всех проектов библиотека стандартных и покупных компонентов, отделённая от
Content Center Inventor и не привязанная к конкретному проекту.

## Требования

| Что | Решение |
|---|---|
| Состав | Всё: ГОСТ, ISO и прочие стандарты; покупные изделия (кабельные вводы, разъёмы и т.п.) разных производителей |
| Объём | Сотни — тысячи позиций |
| Модели | Каждый типоразмер — отдельная модель (`.ipt`, при необходимости `.iam`); без iPart/iAssembly |
| Обмен с другими САПР | Кнопка «Экспорт в CAD-формат»: пользователь выбирает формат (STEP, IGES и др.) |
| Хранение | Файлы — в папке библиотеки на ПК пользователя; сведения о компонентах — в PostgreSQL |
| Права | Чтение — все. Добавление — с допуском. Удаление — администратор или спецдопуск. Пока один пользователь — работает как администратор, учётные записи позже |
| Изменение компонента | Сборки остаются на старой версии, пока пользователь не обновит; перед обновлением — резервная копия сборки (вариант «Б») |
| Content Center | Полностью отделён: из него в библиотеку ничего не попадает, кроме файла, сохранённого отдельно и внесённого через «Добавить в библиотеку» |
| Обозначение стандартных изделий | Строго как в стандарте на компонент |
| Обозначение покупных изделий | `<Наименование> <тип/артикул> <производитель>` (ГОСТ 2.106, «Прочие изделия»), например «Кабельный ввод SKINTOP MS-M 20x1,5 Lapp» |
| Имя файла | Обозначение как есть, с пробелами; заменяются только запрещённые в Windows символы |
| Разделы спецификации | Не делаем; позже — интеграция с системой ГОСТ-спецификаций (отдельный проект пользователя) |
| Наведение порядка в существующих файлах | Нужна утилита (см. ниже) |

## Хранение

Inventor работает только с файлами на диске, поэтому модели хранятся в папке, а база данных
хранит всё остальное:

```
D:\PdmLite\Library\                       ← подключается во все проекты Inventor как библиотека «PdmLite»
  Крепёж\Болты\ГОСТ 7798-70\Болт М8-6gx20.58.016 ГОСТ 7798-70.ipt
  Электротехника\Кабельные вводы\Lapp\SKINTOP MS-M\...
  _versions\                              ← старые версии компонентов (ведёт только PdmLite)
```

PostgreSQL: каталог (классификатор), карточки компонентов (обозначение, стандарт, типоразмер,
производитель, артикул…), версии, контрольные суммы файлов, где используется (какие сборки
ссылаются на компонент), журнал изменений.

Папка меняется только через PdmLite; файлы помечены «только чтение». Пока один пользователь на
одном ПК, роли проверяются в интерфейсе PdmLite; защита на уровне файлов — при переезде на сервер.

Библиотека в проектах Inventor подключается как раздел «Библиотеки» `.ipj` с именем «PdmLite».
Сборки хранят ссылку «имя библиотеки + относительный путь», поэтому папку можно перенести
(на другой диск, позже — в сеть), поменяв только путь в проектах.

## Классификатор

Стандартные изделия — по стандарту, покупные — по производителю:

```
Крепёж ── Болты · Винты · Гайки · Шайбы · Шпильки · Шурупы и саморезы · Заклёпки · Штифты · Шплинты · Кольца стопорные
Подшипники ── Шариковые · Роликовые · Корпусные узлы
Детали машин ── Шпонки · Муфты · Звёздочки и шкивы · Пружины
Уплотнения ── Кольца · Манжеты · Сальники
Электротехника ── Кабельные вводы · Разъёмы · Клеммы · Кабель-каналы · Корпуса · Аппараты
Пневматика и гидравлика ── Фитинги · Цилиндры · Распределители
Прочие покупные
```

Стандартное изделие: Раздел → Группа → Стандарт → типоразмеры.
Покупное: Раздел → Группа → Производитель → Серия → артикулы.
Плюс общий поиск (обозначение, наименование, артикул), фильтры, «Избранное», «Недавние».

## Функции

1. **Добавить в библиотеку** (Inventor и Explorer), сразу много файлов или папка:
   анализ → обязательные проверки (свойства, формат обозначения, дубликаты по обозначению и
   содержимому, внешние ссылки, связь с Content Center, имя файла) → таблица результатов с
   исправлением ошибок → «Внести»: раскладка по классификатору и запись в базу.
   Раздел определяется по стандарту/ключевым словам; ручные исправления запоминаются.
2. **Каталог** в окне PdmLite (Inventor) и в Explorer: дерево, поиск, превью, свойства,
   «Вставить в сборку».
3. **Подключение к проектам**: проверка, что библиотека «PdmLite» есть в активном проекте Inventor.
4. **Отделение Content Center**: библиотеки Content Center в проектах отключаются; компонент
   Content Center в сборке — предупреждение и предложение заменить библиотечным аналогом.
5. **Проверка сборки**: найти стандартные компоненты не из библиотеки (копии в проекте,
   Content Center) → предложить замену → резервная копия → замена ссылок.
6. **Версии**: изменение компонента создаёт новую версию; сборки остаются на старой;
   «Обновить» — с резервной копией сборки.
7. **Экспорт в CAD-формат**: выбранные компоненты → STEP / IGES / … (через Inventor).
8. **Утилита наведения порядка** в существующих файлах — см. ниже.

## Утилита наведения порядка

Для накопленных файлов пользователя (формат Inventor), до массового импорта:
- сканирование папки, чтение iProperties;
- распознавание обозначения и стандарта по свойствам и имени файла;
- групповое редактирование свойств в таблице, правила замены;
- поиск дубликатов (обозначение, содержимое);
- снятие связи с Content Center;
- предпросмотр раскладки по классификатору → передача в «Добавить в библиотеку».

## Порядок работ

| Шаг | Что |
|---|---|
| Б1 | PostgreSQL, модель данных, хранилище, импорт с проверками (Explorer) |
| Б2 | Утилита наведения порядка; первый массовый импорт файлов пользователя |
| Б3 | Каталог в Inventor и Explorer, вставка в сборку, подключение к проектам |
| Б4 | Отделение Content Center, проверка и замена в сборках |
| Б5 | Версии и обновление сборок с резервной копией; экспорт в CAD-форматы |

## Открытые вопросы

1. Будут ли в библиотеке сборки (`.iam`)? По умолчанию — поддерживаются, все их детали тоже в библиотеке.
2. Названия полей, которые ожидает система ГОСТ-спецификаций, — для совместимости свойств.
3. Пример существующих файлов (список имён и свойств) — для правил утилиты наведения порядка.
