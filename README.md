# PdmLite

Мини-PDM для Autodesk Inventor 2025: плагин (add-in) для Inventor и внешнее приложение
для просмотра проекта.

> Статус: **проектирование**. Код ещё не начат — в репозитории только документация.

## Цели

- Дерево проекта во вкладке рядом с браузером модели Inventor.
- Карточка документа (iProperties) с корректным заполнением основной надписи чертежей.
- Переименование документа «везде»: файл модели, её чертежи, iProperties,
  ссылки в родительских сборках — с предпросмотром и откатом.
- «Где используется» / «Что входит» на основе индекса ссылок.
- Внешнее приложение **PdmLite Explorer** — просмотр проекта без запуска Inventor.
- Модульная архитектура: функции подключаются и отключаются как модули.

## Стек

| Что | Чем |
|---|---|
| Платформа | .NET 8, C# |
| CAD | Autodesk Inventor 2025 (Inventor API), Apprentice Server (Inventor View) |
| UI | WPF + MVVM (CommunityToolkit.Mvvm) |
| БД | PostgreSQL + EF Core (Npgsql) |
| DI / логи | Microsoft.Extensions.DependencyInjection, Serilog |
| Тесты | xUnit |
